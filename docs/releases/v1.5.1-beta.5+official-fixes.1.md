# CC Connect 官方修复回移与模型列表刷新

基于自定义版 `v1.5.1-beta.4+relay-live.1`，回移官方稳定版 v1.5.4 中的相关修复，保留已有自定义功能。本版本不是官方 v1.5.4 的整体替换。

- **飞书连接恢复**：升级官方使用的 SDK，修复连接静默失效及重连耗尽后的恢复，补齐共享连接的状态通知。
- **Codex 任务交互**：支持异步提问与回答转向、子线程事件隔离、权限配置及提问超时；修复任务结束判断、连接关闭、会话 ID 保存和大记录读取。
- **会话稳定性**：回移锁代次和失效锁恢复、线程会话隔离、切换保留历史、过期问题按钮处理、空闲状态判定等修复。文字及卡片切换模型均等待当前任务结束后再重启会话。
- **`/model refresh`**：强制拉取当前服务商的模型列表，支持 Codex 和 Claude Code；成功后保存，失败保留旧列表。修复带 `/v1` 地址的拼接；刷新不改变选定模型、不打断任务。卡片提供“刷新列表”按钮，并以模型名绑定选择，避免刷新后排序变化导致误选。
- **保留会话查询优化**：继续使用 JSONL 首行目录过滤及单次遍历建立会话 ID→路径索引，避免 `/list`、`/switch` 查询时重复扫描目录。这是扫描与索引优化，不是解锁算法。

手动登记的模型、通知、自动重试、目录选择、会话恢复和私聊 Relay 功能继续保留。主动刷新展示服务商返回的模型，包括网关自定义名称；具体模型仍需兼容当前 Agent 协议。

源码出处及兼容处理见 [官方修复回移记录](../official-fixes-model-refresh.md)。

## 验证与更新

本版本由 GitHub Actions 执行 Web 构建、工作流/格式校验、Go build/vet、全仓库 race 测试、关键用户流程、Relay 合约及目录权限回归。Actions 对同一合成会话语料比较当前实现与官方 v1.5.4，并构建 Linux、macOS、Windows 的 amd64/arm64 共六种发行包及 SHA-256 校验文件。发布前后均验证发行包与更新器的兼容性。

版本排序 beta.5 高于 beta.4。更新渠道保持 `Eitan-S-23/cc-connect`。各独立实例可通过 `/upgrade` 或 `/update` 查看新版本；安装使用管理员 `/upgrade confirm`，在获准的维护时段执行。发布 Release 不会自动更新或重启实例。
