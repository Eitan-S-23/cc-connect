# Directory browsing: v1.5.1-beta.2+dir-ls.2

This fork prerelease adds /dir ls [page], which lists the current work directory's
real direct subfolders rather than only directories from history.

- Feishu folder buttons switch through the existing /dir session-reset behavior.
- The fixed, equal-width Home / Prev / Next row pages the same directory.
  Home means page 1, not the default work directory or help menu.
- Hidden folders and directory links are included; files and broken links are not.
- Verified operator identity, adapter allowlists and engine command/admin policy
  protect every navigation and selection callback.
- Paging and rejected selections preserve sessions and pending auto-retry.
  Only a successful directory switch cancels the previous continuation.
- A literal folder named ls remains selectable with /dir ./ls.
- Embedded POSIX probes retain LF line endings in cross-platform builds.

The release workflow verifies the full Go repository with the race detector,
critical user journeys, non-root permission regression and the web build before
building Linux, macOS and Windows archives for amd64 and arm64. Each archive has
one executable, and checksums.txt covers all six archives.

The beta.2 precedence allows the built-in updater to move from the previously
unpublished beta.1+dir-ls.test.2 without needing a Release for that test build.
The update channel remains Eitan-S-23/cc-connect, with existing integrity,
architecture, backup and installation-rollback checks.

Use /upgrade (or /update) on the corresponding cc-connect robot to check, then
administrator-only /upgrade confirm when a restart is authorized. This Release
does not update any instance automatically. Updater-incompatible installations
require a separately agreed migration; do not bypass the release-first gate.

Automatic tests do not establish live Feishu App settings or genuine client
button delivery on every installation.
